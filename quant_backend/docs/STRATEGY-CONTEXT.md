# 交易策略决策文档

## 一、核心指标体系

### KDJ双周期压力/支撑线
- 短周期KDJ: Z=5
- 长周期KDJ: Y=55
- **压力线**: J24上穿J时的最高价 (VALUEWHEN)
- **支撑线**: J上穿J24时的最低价 (VALUEWHEN)

### 多周期均线

| 均线 | 用途 |
|------|------|
| MA5 | 超短线趋势，加仓买入参考 |
| MA10 | 短线回调支撑 |
| MA15 | **中短线强弱分界**，站上确认 |
| MA30 | 中线支撑观察 |
| MA50 | **牛熊分界线** |
| MA120 | 半年线，长期支撑 |
| MA240 | 年线，终极支撑 |

## 二、每日自动选股管道

### 扫描范围
- 沪深主板 + 中小板 + 创业板（约4592只）
- 排除北交所
- 后续可加市值过滤（暂未启用）

### 入选条件
1. 当日涨幅 ≥ 8%（大阳线）
2. 连续2天收盘价 > 压力线 × 1.03（有效突破）
3. 涨停标记为重点（主板≥10%，创业板≥20%）

### 自选股管理
- 入选 → auto分组，记录压力位、涨幅、标签
- 手动添加 → manual分组，不受自动踢出影响

### 踢出条件
- 跌破MA100
- 且10天内未重新突破压力位
- 仅踢出auto分组

## 三、市场状态判定

| 状态 | 条件 | 操作倾向 |
|------|------|---------|
| 牛市 | 收盘价 > MA50 | 正常仓位(1/5)交易 |
| 震荡 | 价格在支撑线~压力线之间 | 高抛低吸 |
| 熊市 | 收盘价 < MA50 | 仓位减半(1/10)，只做长期均线反弹 |

---

## 四、买入条件

### P1 最优：突破压力线后回调
1. 股价曾突破压力线
2. 回调到MA10或MA15附近（±3%）
3. 30分钟线出现新支撑（日线用收盘确认替代）
4. 站上确认：收盘 > MA15 且 MA5已上穿MA10
5. 仓位：1/5

### P2 次优：新压力线形成后回调
1. 形成新的压力线
2. 回调到MA10或MA15附近（±3%）
3. 站上确认：收盘 > MA15 且 MA5已上穿MA10
4. 仓位：1/5

### P3 长期均线支撑反弹
1. 回调到MA50/MA120/MA240附近（±3%）
2. 出现企稳信号
3. 站上确认：收盘 > MA15 且 MA5已上穿MA10
4. 仓位：牛市1/5，熊市1/10

### 加仓
- 买入后走势符合预期（持续站上MA15）
- 突破压力线时可在MA5附近加仓
- 每次加仓1/5

## 五、卖出/止盈条件

| 优先级 | 条件 | 操作 |
|--------|------|------|
| 1 | 上涨到压力线附近(±2%) | 止盈 |
| 2 | 突破压力线 | 持有，等新压力线 |
| 3 | 反弹未能突破压力线 | 止盈出局 |
| 4 | 跌破MA15连续2天 | 减仓 |
| 5 | 回调到MA30 | 企稳则持有，否则减仓 |
| 6 | 跌破MA50 | 清仓 |

## 六、关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 均线附近 | ±3% | 收盘价距均线的距离 |
| 站上确认 | 收盘>MA15 且 MA5上穿MA10 | 双重确认 |
| 初始仓位 | 1/5 (20%) | 每只股票 |
| 熊市仓位 | 1/10 (10%) | MA50下方减半 |
| 加仓单位 | 1/5 (20%) | 符合预期时 |
| 压力线突破 | 连续2天 > 压力线×1.03 | 有效突破确认 |
| 踢出条件 | 跌破MA100 + 10天未回 | 自动清理 |
| 大阳线 | 涨幅≥8% | 选股入选门槛 |
| KDJ短周期 | 5 | |
| KDJ长周期 | 55 | |

## 七、回测简化说明

回测中的简化处理：
- P1/P2的30分钟支撑确认 → 用日线"收盘>MA15且MA5上穿MA10"替代
- 加仓逻辑 → 首次1/5，突破压力线时加到2/5
- 止盈 → 到达压力线附近(±2%)时卖出
- 仓位管理 → 回测支持position_pct参数调整
